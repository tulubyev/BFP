# Экспорт данных и методология

Дата: 2026-09-27. Связано: future.md §10 «Этап 6 — экспорт и методология», принципы §3
(у каждого числа — источник, лицензия, дата).

## Экспорт (без миграций)

### Инциденты

- `GET /api/export/incidents.csv|.geojson|.json` — те же фильтры, что у ленты
  (`buildForestChangesQuery` из `backend/services/forestChangesQuery.ts`: `change_type`, `severity`,
  `region`, `start_date`, `end_date`, `sort`, `static_sources`), без пагинации, предел 5000 строк;
  при превышении — 413 с просьбой сузить фильтры (не молча обрезать).
- Поля: id, тип, статус (`metadata.status`), регион, даты обнаружения, первой и последней точки,
  центр, bbox, площадь (с пометкой «оценка сверху, пиксели 375 м» для FIRMS), число точек,
  FRP max, спутники, источник, метод (`metadata.method`), ссылка на инцидент
  (`https://forestwatch.ru/incidents?incident=<id>`).
- Происхождение в каждом формате:
  - JSON: `{ metadata, data }`;
  - GeoJSON: `FeatureCollection` с полем `metadata` верхнего уровня (foreign member, RFC 7946 §6.1),
    геометрия — полигон bbox, если он есть, иначе точка центра;
  - CSV: UTF-8 с BOM (Excel), разделитель `,`, RFC 4180 экранирование; провенанс — колонки
    `source`, `method`, `license` в каждой строке и заголовок `X-Export-Metadata` (JSON)
    с тем же `metadata`.
- `metadata`: `generatedAt`, применённые фильтры, число записей, источники с лицензиями и датами
  (из `sourceRegistry.ts` и журнала загрузок: время последней успешной загрузки FIRMS),
  версия метода кластеризации и маски факелов, ссылка на методологию (`/methodology`),
  предупреждение «кластеры термоточек, не подтверждённые пожары».
- `Content-Disposition: attachment; filename="forestwatch-incidents-<YYYY-MM-DD>.<ext>"`.
- Ответ собирается из БД (без кэша) — это выгрузка; при недоступности БД — 503, не пустой файл.
- Защита от CSV-инъекций: значения, начинающиеся с `= + - @ \t \r`, экранировать префиксом `'`.

### Регионы

- `GET /api/export/regions.csv|.json` — таблица из `regionsService.list()` (`backend/services/regions/`):
  по строке на субъект и показатель (длинный формат): iso, name, indicator id, label, value, unit,
  period, kind, source, reason (если `value = null`). `metadata` как выше + файлы архива FIRMS и
  границ. Пустое значение = пустая ячейка, никогда не 0.

### Интерфейс

- Страница инцидентов: кнопка «Скачать» с выбором CSV / GeoJSON / JSON — выгрузка по текущим
  фильтрам; подпись «до 5000 записей».
- Раздел «Регионы» на странице аналитики: «Скачать таблицу (CSV / JSON)».
- Не трогать `IncidentModal.tsx` (его меняет задача «снимки до/после»; кнопка «Скачать данные
  (JSON)» одного инцидента там уже есть).

## Методология

- Новая страница `/methodology` (ссылка в шапке или подвале и из `metadata.methodology` выгрузок),
  разделы:
  1. Источники — генерируется из `/api/sources` (реестр: владелец, лицензия, частота, разрешение,
     ограничения, свежесть), без ручного дублирования.
  2. Термоточки и инциденты FIRMS: что такое термоточка, кластеризация (≤ 2 км, окно 72 ч,
     только RU-IRK/RU-BU/RU-ZAB), статусы «активен/затих», оценка площади сверху, маска факелов
     (правило истории + ячейки архива `type = 2`), ограничения (облака, пропуски спутников,
     не подтверждённый пожар).
  3. Региональная аналитика: показатели, нормировки (на 10 тыс. км², отклонение от 5 лет),
     «официально / спутник / оценка», почему нет регионального лесовосстановления, оценка GFW
     без ключа (14 субъектов), границы OSM без Крыма и регионов 2022 г. — решение владельца.
  4. Потери покрова GFW/Hansen: потеря покрова ≠ незаконная рубка; DIST-ALERT.
  5. Снимки Sentinel-2: пока одной строкой «снимки до/после в карточке инцидента» (раздел
     дополнит задача про снимки).
- Числа (пороги, окна) брать из констант кода там, где они экспортируются (например,
  `STATIC_MIN_DAYS`), либо проверять тестом, что текст совпадает с константами.

## Тесты (jest)

Сериализация CSV (BOM, экранирование, инъекции, пустые значения), GeoJSON (bbox → полигон,
точка без bbox, foreign member), JSON; предел 5000 → 413; фильтры проходят в
`buildForestChangesQuery`; регионы в длинном формате с `null` → пустая ячейка; маршруты с
поддельной БД; страница методологии рендерит источники из фикстуры.

## Вне рамок

PDF-отчёт по региону, публичный API с ключами, экспорт термоточек.
