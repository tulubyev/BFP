## Технологический стек

### Frontend
- **Vite** - сборщик
- **TypeScript** - типизация
- **Tailwind CSS** - стили

### Backend
- **Express** - веб-фреймворк
- **TypeScript** - типизация
- **PostgreSQL + PostGIS** - база данных

### Тестирование
- **Jest** - тест-фреймворк
- **ts-jest** - TypeScript поддержка

## API Endpoints

| Endpoint | Метод | Описание |
|----------|-------|----------|
| `/health` | GET | Проверка состояния |
| `/api/analytics/*` | GET | Аналитика лесов |
| `/api/stac/*` | GET | STAC каталог |
| `/api/titiler/*` | GET | COG тайлы |

## База данных

Внешняя PostgreSQL на beget.com с PostGIS расширением.

### Основные таблицы:
- `forest_areas` - лесные участки
- `forest_changes` - изменения (пожары, вырубки, болезни)

## Переменные окружения

| Переменная | Описание |
|------------|----------|
| `EXTERNAL_DATABASE_URL` | PostgreSQL (приоритет) |
| `DATABASE_URL` | PostgreSQL (fallback) |
| `STAC_API_URL` | STAC API endpoint |
| `TITILER_URL` | TiTiler endpoint |
