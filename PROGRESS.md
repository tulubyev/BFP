# Журнал выполненных работ — Система мониторинга лесов Байкала

## Дата: 1 февраля 2026 г.

### 1. База данных и инфраструктура
- **Схема БД**: Создана полная структура из 10 таблиц (лесные участки, изменения, снимки, индексы, зоны мониторинга, алерты, пожары, отчеты и справочники).
- **Миграции**: Реализована система миграций и наполнения начальными данными (seed).
- **Данные**: Добавлены сведения о 5 ключевых ООПТ Байкальского региона с **реальными географическими координатами**.

### 2. Аналитические сервисы
- **Спектральные индексы**: Реализован калькулятор индексов NDVI, NBR, NDWI, EVI, SAVI, NDMI с классификацией состояния растительности.
- **NASA FIRMS**: Интегрирован сервис получения оперативных данных о лесных пожарах.
- **Global Forest Watch**: Интеграция с API для получения статистики потерь лесного покрова.

### 3. Веб-интерфейс и Картография
- **Leaflet**: Полноценная интеграция интерактивной карты.
- **Слои**: Подключено 4 типа подложек (OSM, Спутник, Рельеф, Темная).
- **Дополнительные слои**: Добавлены слои «Границы и дороги» и «Населенные пункты» для лучшей ориентировки на местности.
- **Визуализация**: Реализовано отображение лесных участков, зон изменений и термоточек в формате GeoJSON с интерактивными попапами.
- **Управление**: Добавлены кнопки быстрой загрузки слоев и навигации по региону.

### 4. API и Безопасность
- **Endpoints**: Разработано более 15 маршрутов для работы с аналитикой и пространственными данными.
- **CSP**: Настроены политики безопасности для корректной работы сторонних тайл-серверов.
- **GeoJSON**: Реализован экспорт всех пространственных сущностей для ГИС-совместимости.

### 5. Рекомендации по геосервисам в России
Для расширения функционала системы в российском сегменте рекомендуется рассмотреть следующие сервисы:
- **Яндекс Карты (JavaScript API)**: Лучшая детализация адресов и объектов в РФ, отличные спутниковые снимки высокого разрешения.
- **ScanEx (TerraNiva)**: Российский оператор спутникового мониторинга, предоставляет данные сверхвысокого разрешения и специализированные сервисы для мониторинга лесов и пожаров.
- **2GIS API**: Высокая точность карт городов и справочных данных, полезно для привязки лесных участков к инфраструктуре.
- **Роскосмос (Геопортал)**: Доступ к отечественным спутниковым данным серии «Канопус-В» и «Ресурс-П», что критично для импортозамещения.
- **NextGIS**: Российская облачная ГИС-платформа, позволяющая быстро разворачивать веб-карты и мобильные приложения для сбора данных в полевых условиях.

### 6. Процедура подключения к ФГИС ЛК (Федеральная государственная информационная система лесного комплекса)

Для официальной интеграции системы с данными ФГИС ЛК (pub.fgislk.gov.ru) необходимо выполнить следующие шаги:

**Шаг 1: Получение технического доступа**
1. **Регистрация в ЕСИА**: Организация должна быть зарегистрирована на портале Госуслуг.
2. **УКЭП**: Получение усиленной квалифицированной электронной подписи (УКЭП) в аккредитованном удостоверяющем центре для сотрудников, ответственных за работу с системой.
3. **Заявка в Рослесхоз**: Направление официального обращения в Федеральное агентство лесного хозяйства для предоставления доступа к программному интерфейсу (API) ФГИС ЛК в качестве сторонней информационной системы.

**Шаг 2: Настройка интеграции (Техническая часть)**
1. **XML-шлюз**: Реализация программного модуля для формирования XML-запросов по стандартам Рослесхоза.
2. **Авторизация**: Настройка интеграции с ЕСИА для подтверждения полномочий при запросе данных.
3. **Получение данных**:
   - Запрос данных государственного лесного реестра (ГЛР).
   - Получение актуальных лесных деклараций в формате XML.
   - Загрузка актов лесопатологических обследований.

**Шаг 3: Синхронизация данных**
1. **Привязка к координатам**: Сопоставление полученных из ФГИС ЛК границ лесосек с данными спутникового мониторинга в нашей системе.
2. **Автоматический контроль**: Настройка системы алертов — если спутник фиксирует вырубку вне границ разрешенных лесосек из ФГИС ЛК, система автоматически помечает её как «незаконную».

### Текущий статус
Система полностью работоспособна, база данных поддерживает расширенную структуру для данных Рослесхоза, карта отображает актуальные данные из API.
