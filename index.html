☁️ Хранилище данных

  • ✓ Yandex Object Storage - совместимо с S3 API
  • ✓ Beget S3 - бюджетная альтернатива
  • ✓ Формат COG для оптимизации доступа

🖥️ Серверная часть

  • ✓ VPS сервер с Docker (от Selectel, FirstByte, Timeweb)
  • ✓ PostgreSQL + PostGIS через Docker образ
  • ✓ TiTiler в контейнере для динамических тайлов

🚀 План реализации MVP

  • Настройка VPS сервера
  • Установка Docker
Этап 2: Развертывание
  • PostgreSQL + PostGIS
  • TiTiler сервис
  • STAC API
  • Загрузка тестовых данных

  • Карта на MapLibre GL JS

  • Панель управления
